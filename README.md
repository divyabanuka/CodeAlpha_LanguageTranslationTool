# 🌍 AI Language Translation Tool

An AI-powered language translation tool built with Python and Gradio.

## 🚀 Features

- Translate text between multiple languages
- Simple and user-friendly interface
- Supports English, Hindi, Telugu, Tamil, Kannada, Malayalam, Spanish, French, German, Japanese, Chinese, and Arabic
- Fast translation using Google Translator
- Built with Gradio for an interactive web interface

## 🛠️ Technologies Used

- Python
- Gradio
- Deep Translator
- Google Translator

## ▶️ How to Run

1. Install the required libraries:
   `pip install gradio deep-translator`

2. Run the Python/Colab notebook.

3. Enter your text, select the source and target languages, and click **Translate**.
